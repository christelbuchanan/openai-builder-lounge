# Dev Weekly — 2026-04-06

Source: Granola note “Dev Weekly” (scheduled 17:00–17:30 SGT)

## TL;DR
CBV2 auth is working, app-generation via Codex is coming online, and the team is migrating connectors from ChatChat—**but CBV2 must standardize on persistent background workers for all coding tasks**. In parallel, OpenClaw is being positioned as a scoped sub-agent inside ChatChat, with a shell layer migrating from Chat Completions to the Responses API. Longer-term, the team is exploring **proactive event streaming** from connectors and building a **credit-based billing system** shared across ChatChat + Chatandbuild.

## Highlights

### CBV2 progress
- Authentication works with existing user records (users can sign in).
- App-building pipeline is being implemented using Codex.
  - LLM app generation works; reasoning-step display is still buggy.
- Connector migration from ChatChat is underway.
  - Server-side connector code exists; needs testing/validation.
- Key requirement: **all CBV2 coding tasks run via persistent background workers** (Codex desktop app behavior as reference).
- CBV2 must support everything ChatChat supports (connector parity).
- OpenClaw shell integration is needed in CBV2.
- GitHub connector is now considered easier to implement than before.

### OpenClaw / VM architecture
- OpenClaw will run as a **sub-agent** within the main ChatChat agent.
  - ChatChat manages memory; OpenClaw executes assigned tasks via API.
  - OpenClaw itself holds no persistent memory/data.
- Security model: access is **scoped to configured connectors** (limits exposure).
- Shell layer needs migration:
  - Current shell API uses Chat Completions; shell requires **Responses API**.
  - Risk: API switch may affect existing functions; ensure backward compatibility.

### Proactive event streaming (future direction)
- Move from reactive (prompt → response) to **proactive connector-driven events**.
- Poll connectors on a schedule (e.g., every 5 minutes) to push events.
- Example use cases:
  - Flag unanswered emails.
  - Maps + Calendar → detect traffic risk → suggest booking Uber.
- Research owned by Ping An; ties into connector orchestration.
